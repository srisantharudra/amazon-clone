🛒 Amazon Clone

An Amazon-inspired e-commerce website UI built using HTML5 and CSS3. This project recreates the visual appearance of Amazon's online shopping homepage, focusing on page structure, styling, layouts, and user interface design.

🚀 Features

- 🏠 Amazon-inspired homepage layout.
- 🔍 Search bar UI design.
- 📍 Navigation bar and category sections.
- 🛍️ Product display cards.
- 🖼️ Product images and banners.
- 🎨 Custom styling and visual design.
- 📱 Responsive layout (if implemented).

🛠️ Technologies Used

- HTML5 – Structuring webpage content.
- CSS3 – Styling, layouts, Flexbox, Grid, and visual effects.

⚙️ How to Run the Project

1. Clone the repository:
   
   git clone https://github.com/srisantharudra/amazon-clone

2. Navigate to the project folder:
   
   cd amazon

3. Open "amazon1.html" in your browser.

4. Explore the Amazon-inspired website design.
